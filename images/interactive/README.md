# Interactive journey backgrounds

Drop each page's background photo here using the names below. The journey
(`sections/page-journey.html`) already points at these paths, so a photo
appears as soon as its file exists.

- **Format:** `.png` (matches the rest of `/images`). If your photos are
  `.jpg`, say so and the references will be switched in one step.
- **Recommended size:** ~1920px wide, landscape. They're shown full-bleed
  with a dark scrim over them, so slightly darker / lower-contrast photos
  read best behind the text.
